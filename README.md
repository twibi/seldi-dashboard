# SELDI CMS Dashboard

[Check the Dashboard](https://twibi.github.io/seldi-dashboard/)

An interactive, **fully static** dashboard for the regional corruption research
(SELDI Corruption Monitoring System, survey years
2001, 2002, 2014, 2016, 2019, 2021, 2023, 2025).

**One page, one chart, two views** — switched with the *By topic / By country*
toggle above the chart:

- **By topic** (default: Corruption Pressure) — pick one of the **6 topic
  buttons**; countries are compared across the survey years.
  Row 1 of the filters: country multi-select pills + All/None.
  Row 2: survey-year range, chart type (Line/Bar), Reset, Save as PNG.
- **By country** — pick one of the **10 country buttons** and see **all six
  topics as lines** for that country on one timeline.
  Topics the country was not surveyed on are omitted (Romania/Turkey have
  2001–2002 only).

Survey years and chart type are shared between the two views, and the page
heading and insight callout follow the current selection.
Each view can be exported with **Save as PNG** (2× resolution, heading
baked in).

## Topics (one per worksheet)

| Button | Worksheet | Indicator |
|---|---|---|
| Corruption Pressure | 1.Pressure | Experienced corruption pressure |
| Involvement in Corruption | 2.Involvm | Gave bribe/money/favour/gift |
| Acceptability / Tolerance | 3.Acceptability-Tolerance | Acceptability of corruption |
| Likelihood of Pressure | 4.Likelihood | Perceived likelihood of pressure |
| Susceptibility | 5.Susceptibility | Susceptible to accepting/offering a bribe |
| Feasibility of Policy Response | 6.Feasibility of policy resp | Belief corruption can/cannot be reduced |

## Design

- Main colour `#2f3283` (headings, topic buttons) · accent `#ec7627`
  (action buttons, active selectors) · background `#e9e9e9`.
- Line colours follow the **GNOME HIG palette**
  (<https://developer.gnome.org/hig/reference/palette.html>): countries use
  light/dark pairs (Blue 1 & 5, Green 1 & 5, Yellow 1 & 5, Red 1 & 5,
  Purple 1 & 5 — orange and brown skipped); the six topic lines use the dark
  shade of six hues (orange only because a sixth hue is needed).
- Feasibility's insight sentence is generated (the sheet has no insight cell)
  and derived from the sheet's own 2025 values (27.0 %–76.2 %); see
  `extract_data.py`.
- Values displayed as **percent** (the workbook stores fractions 0–1).

## Tech stack

Plain HTML + CSS + JavaScript with [Chart.js 4](https://www.chartjs.org/) from a
CDN. **No build step, no npm, no server-side code** — everything is static files,
which is exactly what GitHub Pages serves for free.

## Updating the data

Data lives in `assets/js/data.js`, generated by `extract_data.py`:

```
python extract_data.py
```

It re-reads `C:\Users\Boris\Downloads\Seldi_CMS_2025.xlsx` (path at the top of
the script) and rewrites `data.js`. The extractor takes the top summary table of
each worksheet (country × year) and skips the SPSS frequency tables below it.

## Layout

```
index.html            the single-page dashboard (GitHub Pages entry)
assets/css/style.css  all styling, scoped under .seldi-root (--seldi-* vars)
assets/js/data.js     generated data (do not edit by hand)
assets/js/dashboard.js view switch, chart, filters, PNG export
assets/vendor/        cached Chart.js for the single-file builds
extract_data.py       xlsx → data.js extractor (incl. Feasibility insight)
build_singlefile.py   builds the WordPress fragment + standalone single file
dist/                 build output — paste (WordPress) or upload (FTP)
v1.zip, v2.zip        backups of earlier versions (not served)
```
